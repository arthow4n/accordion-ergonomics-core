# Does the added pair policy change discovered next actions?

Six index queries from the same recorded C4 state use displacement limits and
sampled integration backtracking. A matched sweep changes only the 16 named
index–middle self-pairs from experiment 019. Both cases discover six sampled
transitions; all distinct endpoints and attempts remain in per-action records.
Best discovered endpoint palm relocations differ by up to 48.97 mm.

This is finite-search and solution-selection sensitivity, not a proven increase
in minimum required movement. Additional pair constraints can redirect a local
solver. Unrequested digits freeze in both cases. Index/middle phalangeal clearance
is enforced under the stated envelopes/tolerance; other anatomical pairs remain
unvalidated. Timing, force and unsampled intervals remain unknown.

Reproduce with `uv run aec frozen sweep
experiments/020-selective-transition-comparison/experiment.json --output artifacts/020`.
Input hashes, model/profile/source versions, identical query lists and both
action atlases are published. These outcomes must not be compared directly to
007's full-board counts: the source C4 pose and solver implementation differ.
